# 👁️ Uyandırıcı - Göz Sağlık

Selam kanka! 😊
Ben biraz yeniyim ama inşallah beğenirsin.

Bu proje, **göz hareketlerini takip ederek kullanıcıyı uyarmaya** yardımcı olmak amacıyla geliştirilmiştir.

## 🔒 Gizlilik

> **Hiçbir bilginiz veya kameradaki hareketleriniz kayıt altına alınmamaktadır.**

Kamera görüntüsü yalnızca uygulamanın çalışması için kullanılır.

## 🚀 Kurulum

Projeyi çalıştırmak için gerekli Python kütüphanelerini yüklemen gerekiyor.

CMD'yi açıp şu komutu yazabilirsin:

```bash
pip install -r requirements.txt
```

Kütüphaneler yüklendikten sonra programı şu komutla çalıştırabilirsin:

```bash
python goztakip.py
```

## 📦 `.bat` Dosyası Ne İşe Yarıyor?

`.bat` dosyasının olduğuna bakma 😄

Sadece Python programını **daha hızlı başlatmak** ve gerekli kütüphanelerin kurulumunu kolaylaştırmak için ekledim.

İstersen `.bat` dosyasını hiç kullanmadan da programı çalıştırabilirsin.

Komutları kendi CMD'ne yazarak da aynı işlemleri gerçekleştirebilirsin. 👌
